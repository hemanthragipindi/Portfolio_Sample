## 💡 Customization Highlights

### Super Easy to Edit
Everything is in **one file:** `src/data/portfolioData.js`

```javascript
export const personalInfo = {
  name: "YOUR NAME",           // Change this
  role: "YOUR JOB TITLE",      // Change this
  email: "your@email.com",     // Change this
  location: "Your City",       // Change this
  bio: "Your bio here",        // Change this
};
```

### Add Your Projects
```javascript
export const projects = [
  {
    title: "Your Project Name",
    description: "What it does",
    technologies: ["React", "Node.js"],
    liveUrl: "https://your-project.com",
    githubUrl: "https://github.com/your-repo",
  },
  // Add more...
];
```

### Change Colors
File: `index.html`
```html
<style>
  :root {
    --color-accent: #3b82f6;  /* Change this! */
  }
</style>
```

### Add Images
1. Create `public/images/` folder
2. Add your profile photo
3. Create `public/projects/` folder
4. Add project images
5. Update paths in `portfolioData.js`
